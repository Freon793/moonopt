# 算法说明

本文件写**实现里真正在跑的是什么**，以及每个策略背后那条**实测数字**。项目座右铭是"每个结论都要为它依赖的
假设付一次测量"，所以下面几乎每一段都以一条可复核的数字结尾；数字的出处是 `CHANGELOG.md`（逐轮实测记录）、
`bench/*.md`（报告，可由脚本复现）或本文给出的命令。

## 1. 模型层与标准形

模型层接受 `min/max`、`≤`/`≥`/`=`、任意有限上下界、自由变量与整数标记。交给内核时一律化成
`min cᵀx, A x = b, l ≤ x ≤ u`：

| 模型层构造 | 内核层变换 |
| --- | --- |
| `x ≥ lb` | 代换 `x = lb + y`（`y ≥ 0`）：列系数×`lb` 移到右端项，`c·lb` 计入目标常数 |
| `x ≤ ub` | **列上界**（不占行：比值检验两个方向都读） |
| `ub < lb` | 显式行 `Σ sign·y ≤ ub − lb`，负右端项让运行报 `Infeasible` 而不是把负区间交给内核 |
| 下界无界 | 拆成 `x = p − n` 两个非负列；若上界也有限，额外加一行 `p − n ≤ ub`（两列之差没有单列界） |
| `a·x ≤ b` | 松弛列 `+1` |
| `a·x ≥ b` | 剩余列 `−1` + 人工列 `+1` |
| `a·x = b` | 人工列 `+1` |
| 右端项为负 | 整行取反并交换 `≤`/`≥`（保证起始基存在） |
| `maximize` | 代价与目标常数取反，`model_sign` 记回程符号 |

**为什么"上界不是行"值得单独说**：内核**枢轴数随行数走、与列数几乎无关**（覆盖型 LP 探针：
20/40/120/240 行 → 57/137/632/2220 枢轴；20 行时 100 列与 900 列分别是 57 与 35）。
`fast0507` 在"每个有限上界一行"的旧口径下是 63490 行，去掉之后是 489 行，每次枢轴从约 47.5 ms 降到 2.4 ms。

**证书回映**：内核的行是归一化过的（关系符号、右端项为负时整行取反），证书必须按模型自己的行陈述，
所以每个内核行带两个因子：`row_dual_factor`（回映**乘子**用，含关系符号与整行取反）与
`row_sign`（回映**系数**用，只含整行取反）。这两个数**不是同一个数**，用错会给每个取自 `≤` 行的割带符号错误
（`CHANGELOG.md` M5 第十轮）。等式性另存 `row_relation`——符号约定只对 `≤`/`≥` 限制，`=` 行自由，
而上面两个因子的量级恒为 1，答不出这件事（第十五轮）。

## 2. 修正单纯形内核

- **稀疏 LU 基分解** `P·B = L·U`（行主元相对阈值）+ **乘积形式（eta）基更新**：内存 `O(nnz + fill)`。
  重新分解间隔默认为 500 个枢轴；填充量由 `max_factor_entries` 预算约束（稀疏分解唯一无法事先预测的量）。
- **有界变量枢轴**：非基变量停在上下界之一；比值检验同时读两种限制（基本变量落到零、基本变量升到自己的上界）
  以及进入变量自身的区间。**枢轴的步长必须由比值检验所选行给出**，不能在 pivot 里从行反推——
  两个界都在时"离开变量落到哪个界"决定步长怎么读，零步长的人工驱逐枢轴必须显式传 0
  （否则会拿到无界列的 `1e30` 哨兵当步长、一步写出 `1e32` 的状态；`CHANGELOG.md` 记录过这次误报）。
- **定价**：Dantzig + **实测增益**。检验数是**改进速率**，实际增益是 `|r| · step`，两者可以差一个数量级
  （`fast0507` 实测：Dantzig 选 `r = −121.1`、步长 `0.00632`、增益 `0.76`，而抽样里有 `r = −6`、步长 `1.0`、
  增益 `6.0`）。改成"每迭代对有界候选集测实测增益再选列"后，同一枢轴预算下目标值 165.1 → 156.8（20000 枢轴）、
  → 133.0（45000 枢轴；Dantzig 要 250000 枢轴才到 160.4），每次枢轴增益提升约 40×，代价是每次枢轴 2.4 → 14 ms。
- **Harris 两遍比值检验 + 可行性守卫**、**退化扰动**（确定性模式，默认 `1e-12`；扰动只用于打破平局，
  自检与答案门禁一律按**未扰动**右端项测量）、**停滞窗口触发 Bland 规则**（固定窗 500 个枢轴，
  不随 `m` 变——旧口径 `2m + 50` 在 63490 行的实例上要求 127030 个连续不改进枢轴，等于永远不会触发；
  **目标重新有改进就解除闩死**：兜底是给"目标不再响应枢轴"的，闩死不解的代价是实测的
  ——`mod010` 15 527 → 3455 个枢轴、20 实例总枢轴 24 408 → 12 336（−49%），其余 19 个逐位不变。
  解除不丢保证：循环是**零改进**，会在窗口内重新触发；`start_with_bland` 的恢复尝试保持闩死）。
- **自检（内核为什么"宁可报失败"）**：三角求解只保证**残差**小、不保证**误差**小（病态基上差一个条件数），
  所以每个结论都要量它所依据的那个方程的残差：
  对偶量 `c_B − Bᵀy`（一步迭代精化把 `noswot` 某节点从 `3.7e-7` 降到 `4e-13`，而那一点真乘子是 0 ——
  校验器拒签是对的）、方向量 `aⱼ − A·d`（每迭代自检；
  一次差值 20 的枢轴曾让一个有界节点被报成无界）、非负性**按逐变量**量（曾按整个解的最大元素缩放，
  `-7.7e-7` 挨着 `1e5` 量成 `7.7e-12` 放行，而校验器按 `raw/(1+|xⱼ|)` 量成 `7.7e-7` 拒签）、
  以及**行乘子的符号约定**（第十五轮加：按校验器同一条式子 `raw · max|aᵢⱼ| / max|cⱼ|` 量，
  超容差先 `refactorize()` 重测，仍在容差外就报 `NumericalFailure` 而不是发出注定被拒的证书）、
  以及**对偶间隙**（第二十八轮加：前两条各说一半 —— 点是可行的、乘子写得出来 —— 都不说
  **乘子证明的那个界**是否等于**这个点有的目标值**，而后者才是最优性主张的全部内容。
  式子与尺度逐字取校验器的那一条：`|primal − L| / (1 + |primal| + |L|)`，框极小值的规则相同
  （容差只管指向哪个界，值按界照实算），分母、哨兵也相同；模型自己的系数、界与右端项由
  `KernelProblem::model_cost` / `model_lower` / `model_upper` / `model_rhs` 一路带过来，
  而不是从标准形反推 —— 生产者量"校验器输入的还原"而不是输入本身，这个错误本项目犯过三次）。
   **这几条自检的开销量过**（短路法，20 实例、上限 20000）：方向残差自检 −0.05%（噪声内）、
  枢轴稳定性校验逐位相同（本清单上从不触发）、每枢轴的时钟成本 1.55 ms（有自检）对 1.57 ms（去掉）——
  一个迭代由增益定价决定，所以**自检的代价在"把运行送上哪条枢轴路径"上，而不是在时钟上**；
  全表见 `CHANGELOG.md`。**间隙自检的时钟没有单独量**：它只在一次成功求解的收尾跑一遍
  （结构列一遍、模型行一遍），不随枢轴数增长，那是结构性论证、不是实测数字；它的**间接**代价
  在语料上看得见 —— 触发 `refactorize()` 会换一条树（见 `CHANGELOG.md` 第二十八轮的数字）。
- **恢复路径**：数值失败时从初始基重启一次、改用 Bland 规则并缩短重新分解间隔；恢复结果同样过全部自检，
  仍失败则返回**原始失败**并标注（"换了一条路走通"和"原来那条路是对的"不是一回事）。

## 3. 对偶单纯形热启动

改界之后**检验数不变**（它们只依赖基与目标），所以上一次的最优基对子问题仍然对偶可行，缺的只是原始可行性——
这正是对偶单纯形修的东西。契约是"只是提速，永不给出不同答案"：形状不匹配、对偶可行性丢失、数值失败一律回退冷启动。
**加行之后的热启动**（第十七轮实现并实测）走同一条论证：新行乘子从 0 起 ⇒ 检验数不动、基仍对偶可行；
把新行自己的松弛/剩余列（**不能用人工列**，它会吸掉违反量）设为该行基变量，其值就是"点违反该行多少"，
对偶单纯形修它。实测把"每个候选割都重解一次"的代价从 45.8 s 压到 1.0 s（`22433`，14×）。
但把它用在**割轮整轮重解**上会落到退化最优面的另一个顶点、传给子节点的基随之改变，实测改树变差
（`p0201` 586 → 808 节点）——所以只许用在测量上。

## 4. Presolve 与 postsolve

归约：空行/列、冗余行、singleton 转界、隐式界收紧、固定变量消元（含目标偏移）。
**每条归约先证明再触发**；化简证出的 `Infeasible`/`Unbounded` 直接作为结论上报，不交给内核。
回程：`reconstruct` 把化简解映回原变量，调用方用 `max_row_violation`/`max_bound_violation`/`objective_value`
在**原模型**上复核——化简自己的记账不是证据。
实测（`bench/solve-report.md` 口径）：`30n20b8` 被化简掉 7282 个变量（18380 → 11098，内核行 18956 → 11591，降 39%），
稀疏 LU 之后 11591 行 16 秒解到最优；而集覆盖型的 `fast0507` 几乎没有可约的上界行（63009 → 63001 个变量）。

## 5. 割平面（MIR / Gomory 混合整数舍入）

**割是"一行 + 它由哪一行舍入而来的证明"**，证明 = 模型行的组合（`rⱼ = Σ yᵢaᵢⱼ`、`β = Σ yᵢbᵢ`）。
混合整数舍入要求：基变量是整数且系数为 1、行内其余变量都由**有限界**写成非负变量、
连续变量只能按 `ā/f₀` 或 `−ā/(1−f₀)` 进入（它不能当计数器）。

独立复核 `verify_cut` 把这一行**重算一遍**并逐条量：组合重现自称的行、基变量整数、有限界移位、
小数部分按 `combination_noise`（产生这一行的算术有多大）而非绝对值判、**割必须大于产生它的算术**
（否则等于凭舍入噪声宣布"没有整数点存在"）、与交上来的行逐项相同。拒绝即停成 `Unverified`。

**为什么割值得这么多防线**：一条无效割会把整数点（可能是真最优）从它落地的节点起删掉，
而**现有每条防线都会继续点头**——后续松弛被正确求解、证书拿带割的模型去校验、报告的点复核也拿带割的模型量。

**实测**：加割之后 `khb05250` 用 **305** 个节点证到 106940226（不加割要 **7552** 个节点、293.6 s），
`p0201` 586 节点证到 7615（不加割在 20000 节点内证不出），`22433` 33 节点（不加割 59）。
**选择规则（第十六~十八轮）**：一轮里的候选割在**违背量上完全并列**（每个单行割在被导出的点上恰好违背
一个自身尺度单位），所以"按强度取上限"实际是按行序截断；量过五种规则（efficacy、单条实测增益、
联合增益贪心、上限翻倍）**没有一条在"界"与"证明成本"两个轴上同时赢过"行序取满上限"**。
结论写在 key 记忆与 `CHANGELOG.md` 里：**割的价值是"树"的属性，不是"根松弛"的属性**
（一条对根松弛毫无推动的割仍会割更深节点的松弛），所以选择规则这条线关闭。
`markshare1`/`markshare2`/`pk1`/`noswot` 的根界增量是 **+0**（0/2/6 轮都是），它们要的是更强的割族而不是更好的选择。

## 6. 分支定界

- **best-bound**：界是最好的剪枝依据（没有最优解可比时，界剪不掉任何东西）。
- **节点 = 父节点 + 一条收紧的界**，沿链从根重建；子节点从父节点的最优基**热启动**。
- **incumbent 的 cutoff 花在盒子上，而不是加一行**（第二十四轮）：找到当前整数点之后，"值得找的点必须比它更好"
  就是一条关于目标的约束；目标逐项求和，于是把一项用 cutoff 与**其余各项在各自盒子上的最小可能贡献**夹住
  （`value_k·x_k ≤ cutoff − Σ_{j≠k} min_j`），就单独给这个变量定界，整体 `O(n)`，空盒子直接剪掉、连一次求解都不花。
  与"加一行 cutoff 约束"在剪枝上等价（一行只在松弛已经知道它能更好处活跃），但收窄的盒子还会收窄后续分支。
  报告口径实测：32 实例 300 节点口径只有 `gt2` 一行的界在 1e-15 相对量上变（舍入级），小规模 20000 节点口径里
  `markshare2` 的当前解 192.00000000369937 → **144.99999999986127**，4 个已证最优实例一字未动。
- **取整启发式（下潜）**：走最分数变量较近的整侧、重解、往复，落到可行整点为止。
  两条实测判断：① "两个方向都不可行"**不是**"卡在这个变量上"，而是"这个区域已证明没有整数点"
  （`x ≤ ⌊v⌋` 与 `x ≥ ⌈v⌉` 覆盖所有整数取值），此时正确动作是放弃这次下潜；
  ② 每步步数不是 `2×分数变量`——那只是**下界**（一步重解可能让另一个变量变成分数），
  所以每次启动给满 `dive_steps`（默认 60：`pk1` 30 步内从 12 个分数变量降到 1 个、60 步内落地；
  `markshare1`/`markshare2` 只在 60 步预算下才出解）。启动门槛是实测的：`depth ≥ 分数变量个数`。
- **割只在根**：根的割被整棵子树继承，这样"节点=父节点+一条界"的形状与节点间热启动都保持不变。
  割轮次只有在重解**给出结论且不变差**时才保留，否则整轮丢弃（`noswot` 上 20 条割曾让根重解跑不完，
  原始写法让整个运行在 3 个松弛后结束、界为 0，比不加割严格更差）。**切几轮按收益走**（第三十一轮）：
  前两轮无条件照旧，之后只有上一轮把根界抬了至少 `cut_round_gain`（1.4%）才再开一轮，轮数上限由 `cut_rounds`
  （默认 4）界住 —— 实测 `khb05250` 每轮加 `5.6 / 2.4 / 1.5 / 0.4%`、证明成本 `305 → 185 → 114` 节点，
  而 `p0201` 第三轮只加 0.5% 却把证明从 586 拖到 1135、`flugpl` 第三轮加 0.02% 把 13806 拖到 14938。
- **`verified` 与"无结论"**：每个松弛都在分支前过校验；`verified < nodes` 的差额是"到达不了结论的松弛"
  （迭代上限、或最优基写不出满足符号约定的证书），它们按**开着的活**计，而不是按"被拒的主张"结束整轮运行。
- **报告的界取在"开着的活"上，而不只是队列上**（第二十九轮）：一个松弛没有结论的节点被弹出后**不会重新入队**
  （再解一次是同一份工作、同一个结论），但它的键是**父节点的松弛目标值**，对它整棵子树都是有效的界 —— 只遍历
  队列会把这份界连同子树一起丢掉，而 best-bound 弹出的正是键最小的那批节点、**最小的键就是报出的那个数**，
  所以丢掉的方向是"界报得更好看、gap 报得更小"。现在 `open_bound` 取队列的键 ∪ 被丢下节点的键（节点本身仍
  不入队）；预算到顶的消息把"仍在队列的树节点"与"到达不了结论的松弛"分开说。实测（小规模 20000 节点口径）：
  `blend2` 的界 `7.5784463643777125` → `7.399764899326714`（−2.36%），`verified` 汇总与 4 个已证最优一字未动；
  300 节点口径**无一行变化**。**注意两类"没有结论"的分工**：主循环的节点丢的是界（所以要计进去），**下潜的一步
  不丢界**（出发节点有结论，分支出来的子节点仍带着那个结论），它只体现在 `nodes − verified` 的差里。
- **下潜的储备（第三十轮）**：一个跑掉半个预算**还没有任何整数点**的运行，既没有东西可剪枝、也没有东西可报告
  （报告里就是 `objective` 空 + `gap` `1e300`）—— 它把 `dive_attempts` 次走法花完就只能等运气。于是给它留一份
  **预算份额**的储备（`max_nodes / 16`）用于额外走法，条件是"过半仍无当前解"**且**"储备能负担一整次走法
  （`dive_steps` 步）"。第二条是实测出来的：只装前一条时，300 节点口径五行界被拉低却一个点没找到（储备 18 步 <
  一次走法），加上它之后那五行逐字节相同，而 20000 节点口径的 `blend2` 第一次拿到整数点。
- **公开口径**见 `docs/api.md`：只有搜索证明过的结论才变成公开状态。
- **报告**：`bench/mip-report.md`（32 实例、300 节点口径）、`bench/mip-report-small.md`
  （10 实例、20000 节点口径：4 个证到公开已知最优值），对拍脚本 `bench/check-mip-objectives.ps1` 要求**取等**。

## 7. 证书与校验

最优性证书 = 可行点 + 满足符号约定的行乘子 + 互补松弛 + 对偶间隙为零；不可行证书 = 同一式子取 `c = 0`
并要求严格为正（Farkas）；无界证书 = 可行点 + 改善射线。校验器 `verify` 复算全部四项并给出逐项测量，
`Verdict::reason` 是**第一处失败的原话**（不是"拒绝"两个字）。
**已知限度，现已由生产端守卫收口（第二十三轮）**：Farkas 射线的**构造**仍是"Phase I 的最优对偶解"，
而不是从 Phase I 状态显式导出的构造；区别在于内核现在**先自检再发**：人工和必须能吸收它要解释的违反量
（`Σ a ≥ max v`，`simplex/certificate.mbt::infeasibility_is_certified`，判据用残差测试自己的
`infeasibility_margin`），不成立就报 `NumericalFailure` 而不发证书 —— 这条条件是实测夹出来的：`noswot`
节点 1558 上原始残差 `1.94e-6` 而人工和只有 `1.2e-11`（相差 5 个数量级），那种 duals 的 `farkas margin`
恰为 0，校验器必须拒签，而拒签会把一次正常的搜索整轮停掉。现在这类状态按"没有结论的松弛"计（`verified < nodes`），
搜索继续；真正可证的不可行照旧发证书、照旧由校验器裁决。完整数字见 `CHANGELOG.md` 第二十三轮。

## 8. 数值策略摘要

- 容差感知比较（`approx_*`），绝不用 `==` 比浮点；
- 补偿求和用于所有多项累加（目标值、行内积、组合系数）；
- 每个"是否为零/是否为正"的决策都带尺度：残差按行尺度、非负性按逐变量、乘子符号按
  `raw · max|aᵢⱼ| / max|cⱼ|`、割的小数部分按产生它的算术规模；
- **自检的尺度必须与它所替代的那个检查一致**——本项目为此踩过三次坑（`max_negativity`、
  割的 `row_scale`、节点容差口径），三次都写在 `CHANGELOG.md` 与 key 记忆里；
- 任何可能数值失败的例程都必须**显式报告失败**，不许悄悄返回一个看起来合理的答案。
