# 路线图（10 天计划、硬开关与非目标）

本文件是开发与验收的唯一进度口径。每日产出必须真实提交（禁止空提交与无意义拆分）。

## 交付分级

- **底线（必达，任何情况下都要交付）**：`model` 通用模型 + `format` MPS/LP 读写 +
  稀疏修正单纯形 + `verify` 证书校验器 + CLI + 至少一个可运行示例 + CI + 发布到 mooncakes。
  做到这一步即是一个“真实可用、边界清晰”的库。
- **目标**：Netlib LP 数据集多数实例解到公开已知最优值，并给出可复现成绩表
  （含**未解出实例的诚实统计与原因**）。
- **加分**：薄 MILP 层（分支定界复用自家 LP 内核）、割平面、更大规模实例。

## D7 硬开关（预先约定，避免临时妥协）

**若 D7 结束时**“MPS/LP 读写 + 稀疏修正单纯形 + 对偶单纯形 + presolve + 证书校验 + Netlib 对拍”
仍有任一未绿，则**立即砍掉 MILP 层**，把 D8–D9 全部投入稳定性、文档与基准报告；
MILP 顺延到 v0.2，并写入下方“非目标”的“本版本不做”一节。

理由：生态邻居（job-shop、VRP、排班、装箱）本质是 MIP，MILP 能显著加强生态位叙事，
但它的正确性完全建立在 LP 内核之上；LP 内核不稳时做 MILP 只会放大错误。

## 明确不做（非目标）

本版本不做，且会在 README 与文档中明确标注，避免夸大承诺：

- 非线性 / 凸优化（NLP）、半定规划；
- 随机规划与分解算法（Benders、Lagrangian 松弛）；
- 并行 / 多线程求解；
- 网络单纯形专用高速路径（不追求大规模网络流实例的顶尖性能）；
- MPS 的极小众扩展（完整 `MARKER` / `SOS` 语义）与 CPLEX LP 格式的全部扩展；
- Python / JS 绑定（保持纯 MoonBit、零 FFI）。

## 规模承诺的措辞

不写“目标万级约束/变量”。对外只报告**实测**：以 Netlib 实例规模分布为参照，
列出“≤ 2 000 行实例 X/Y 解到已知最优”，更大实例逐条给出结果与原因。
