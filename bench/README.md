# 基准数据与报告

## 数据政策（重要）

**本仓库不再分发第三方测试数据集。** 只提供来源说明、下载脚本与校验信息。

| 数据集 | 来源 | 许可证 / 使用说明 |
| --- | --- | --- |
| Netlib LP test set | <https://www.netlib.org/lp/data/> | Netlib 明确要求以 netlib 的请求/下载方式获取；本仓库只保存下载脚本与实例清单 |
| MIPLIB | <https://miplib.zib.de/> | 按其站点许可与引用要求使用；同样只保存脚本与清单 |

数据下载后放在 `bench/data/`（该目录已在 `.gitignore` 中忽略），报告与清单可以提交。

## 计划产出

- `bench/report.md`：每次全量跑的结果表 —— 实例、规模、状态、目标值、与公开已知最优值的
  相对误差、迭代数、耗时。**未解出与超时实例必须逐条列出并给出原因。**
- `bench/netlib.json`：实例清单（名称、规模、公开已知最优目标值、来源引用）。
- `bench/run.sh` / `bench/run.ps1`：下载 + 批量运行 + 生成报告的脚本（D4 落地）。

## 报告原则

1. 只报告**实测**结果，不写目标值以外的推测；
2. 失败要显式：超时、迭代上限、数值失败、超出能力边界分别统计，不合并成“其他”；
3. 每次报告携带运行环境（`moon version --all`）与提交哈希，保证可复现。
